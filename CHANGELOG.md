# Changelog

## 0.1.0 - unreleased

First release.

- Records which application takes the foreground, when, and why it counted as a theft
- Watch, guard and strict modes, switched from the tray
- Hands focus back to the window you were in, and flashes the interrupting window
- Block and allow lists, editable by right-clicking a line in the log
- Turns the Windows foreground lock timeout back on
- Log window, log file, optional start with Windows
